# Islands Discord theme

> [!WARNING]
> Heavy work in progress, don't expect everything to be fully functional or polished.

A heavy work-in-progress theme centered around the idea of separate UI elements being distinguishable 'islands'. Slightly inspired by other themes and Microsoft Fluent UI design.

```css
@import url("https://astro-aya.github.io/ayas-random-css/Themes/Islands/islands theme.css");
```
